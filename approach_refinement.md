# TRUSTCORE ADVISORY Approach Page — UX Refinement Blueprint

## Audit summary

The current page presents an elegant four-step philosophy, but it does not yet make the practical experience of an engagement obvious enough. A visitor should understand the process in seconds: **bring a question, get clarity, agree the focus, and make useful progress**. The refined page will retain the calm editorial tone while giving each process moment a clear visitor benefit and tangible output.

## Revised visitor journey

| Moment | Visitor needs to understand | Design response |
| --- | --- | --- |
| Arrival | What TRUSTCORE’s approach feels like | A concise promise supported by a calm contextual image. |
| Orientation | The process in one glance | A visual engagement ribbon: question → clarity → focused action. |
| Confidence | What happens in each phase | Four process panels pairing action, visitor benefit, and expected output. |
| Reassurance | Whether the approach is workable | A “designed for real operations” proof band with practical principles. |
| Conversion | How to begin | A direct, no-pressure consultation action. |

## Navigation correction

The shared site shell will reset `window.scrollTo(0, 0)` whenever the route changes. This prevents the browser from retaining the previous page’s scroll position when a visitor chooses a new navigation link.
